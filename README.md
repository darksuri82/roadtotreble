# PITCH MANAGER — 유럽 5대 리그 드래프트 & 시뮬레이터

React (Vite) + TypeScript + Tailwind CSS v4 기반 축구 드래프트 & 유럽 5대 리그 시뮬레이션 웹 게임입니다.

## 주요 기능 (Phase 1)
- **분리된 데이터 구조 (`src/data/`)**: 유럽 5대 리그 현역 선수 180명(OVR 76~90), 올타임 레전드 28명(OVR 91~96), 5대 리그 96개 구단
- **초기 드래프트**: 4-3-3 / 4-4-2 / 4-2-3-1 포메이션 선택 후 선발 11명 + 벤치 5명 드래프트 (중복 금지, 등급 확률 48.5% / 38% / 12% / 1.5%, 레전드 골드 글로우 연출)
- **케미스트리 (0~100)**: 구단·리그·국적 일치 가점, 레전드 와일드카드 자동 리그 연결
- **5대 리그 풀 시즌**: 최하위 팀 대체 편입, 홈/원정 더블 라운드 로빈(38R/34R), 포아송 분포 경기 엔진, 1~4위 챔피언스리그 진출권 하이라이트
- **시즌 중 3회 이적시장**: 38R(10R/19R/28R) · 34R(9R/17R/25R) 종료 후 오픈, 회당 영입권 2회, 4위 이내 시 레전드 확률 2.5% 상향
- **Phase 2 연계 준비**: 4위 이내 달성 시 챔피언스리그 진출 배너 및 `Phase2HandoffState` 저장
